# 🐛 Bug AI Test

一个专门用于测试 AI Debug 能力的四级 Bug 靶场。

## 难度

| 等级 | Bug | 核心能力 |
|---|---|---|
| 🥉 青铜 | 重复提交 | 基础状态管理、幂等性 |
| 🥈 白银 | 刷新状态丢失 | 状态持久化、URL/Storage |
| 💎 钻石 | 乱序响应 | 并发控制、请求取消/版本化 |
| 👑 王者 | Token 竞态 + 越权 | 认证并发、对象级授权 |

## 启动

需要 Node.js 20+：

```bash
npm test
npm start
```

然后打开 `http://localhost:3000`。

## 规则

这是**故意有 Bug 的靶场**。初始状态下测试应暴露缺陷；挑战目标是：

1. 找到四个 Bug 的根因。
2. 修复实现而不是绕过测试。
3. 保持 API 行为合理。
4. 补充回归测试。
5. 不使用真实 Token、密码或生产数据。

## AI 挑战

可以把下面这句话直接交给 AI：

> 请检查这个仓库，找出并修复所有青铜、白银、钻石、王者级 Bug。运行测试验证，并说明每个 Bug 的根因和修复方案。

## 安全说明

王者级关卡只使用本地模拟用户和虚构 Token，不连接任何真实认证系统。任何越权测试都应限定在这个本地靶场环境中。
